# Swiggy Restaurant Data Analysis

## Project Overview
This project focuses on analyzing Swiggy restaurant data using MySQL to understand restaurant ratings, pricing, delivery time, and city-wise distribution.

## Tools Used
- MySQL
- SQL
- CSV Dataset

## Dataset
The dataset contains restaurant details such as city, area, restaurant name, price, average ratings, total ratings, food type, address, and delivery time.

## Project Objectives
- Perform data cleaning and identify duplicate and NULL values.
- Analyze restaurant distribution across cities and areas.
- Identify highly rated and expensive restaurants.
- Analyze average prices and ratings by city.
- Evaluate restaurant delivery times.

## SQL Concepts Used
SELECT, WHERE, GROUP BY, ORDER BY, HAVING, COUNT(), AVG(), ROUND(), CASE, CAST(), and aggregate functions.

## Files Included
- `swiggy.csv` – Dataset
- `swiggy.sql.queries.sql` – SQL queries used for data cleaning and analysis

## Conclusion
This project demonstrates practical SQL skills in data cleaning, data analysis, and extracting insights from restaurant data.
